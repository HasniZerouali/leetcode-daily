# LeetCode Daily (NeetCode 250)

Solving one problem every day from the [NeetCode 250](https://neetcode.io) roadmap.

### Daily Flow
1. **Scaffold problem**:
   ```bash
   python3 new_problem.py <number> <slug> <topic> <difficulty>
   ```
2. **Solve & document**:
   - Write solution in `problems/<topic>/<number>-<slug>/solution.py`
   - Fill in details and takeaways in `problems/<topic>/<number>-<slug>/README.md`
   - Add a row to the table below.
3. **Commit & push**:
   ```bash
   git add .
   git commit -m "solve: <number> <slug> (<difficulty>)"
   git push
   ```
